D. APERSEPSI

Informasi dapat disimpan menggunakan variable, misalnya nama, kelas, umur, nilai, dan jurusan. Setiap variable diberi nilai sesuai data yang ingin disimpan.

E. AKTIVITAS 1 – MENGAMATI

let nama = "Budi";
let umur = 16;
let nilai = 85;
console.log(nama);
console.log(umur);
console.log(nilai);
1. Console menampilkan Budi, 16, dan 85.
2. nama, umur, dan nilai adalah variable yang menyimpan data siswa.
3. console.log(nama); menampilkan nilai yang tersimpan dalam variable nama, yaitu Budi.
4. Variable adalah tempat untuk menyimpan data agar dapat digunakan kembali oleh program.

F. AKTIVITAS 2 – MENGENAL VARIABLE

Variable adalah tempat untuk menyimpan sebuah data agar data tersebut dapat digunakan kembali oleh program.
let nama = "Andi";
let membuat variable, nama adalah nama variable, = memberikan nilai, dan "Andi" adalah nilai yang disimpan.

G. AKTIVITAS 3 – PRAKTIK MEMBUAT VARIABLE

Hasil pengamatan Console:
Nama: Budi
Kelas: XI RPL 1
Umur: 16

H. AKTIVITAS 4 – EKSPERIMEN

1. Ya, hasil pada Console berubah sesuai data baru.
2. Nilai pada variable nama, kelas, dan umur diubah.
3. Program menampilkan data baru karena nilai variable telah diganti.

I. AKTIVITAS 5 – BERBAGAI DATA

nama = "Andi" → String (teks)
umur = 17 → Number (angka)
tinggi = 170 → Number (angka)
aktif = true → Boolean
Data yang ditulis menggunakan tanda kutip merupakan data String/teks. Data 17 merupakan data Number/angka.

J. AKTIVITAS 6 – let DAN const

Hasil let umur = 16; umur = 17; adalah 17.
Pada const, nilai tidak dapat diubah setelah dideklarasikan sehingga akan menghasilkan error.
let: nilai dapat diubah dan digunakan untuk data yang masih mungkin berubah.
const: nilai tidak dapat diubah dan digunakan untuk data yang tidak perlu diubah.
